# 交接模板

> 用法：一个对话做到一半要交给下一个对话时写。交接固定写在项目根 `交接_最新.md`；写新交接前先把旧的 `git mv` 进 `交接归档/`、用它原来的日期名；新稿在别处整份写好，再落到固定文件名上，不在固定文件名上边写边存。
> 五节、顺序固定，限长约 3 千字（提醒线）。值守每轮用 `pipeline/ledger_check.py` 查：缺节、超长、第③④节指旧交接、引用的账上编号不存在或已结、某步缺「算对：」行——只提醒，不拦流水线。
> **三句话边界**：(a) 待办「有没有、归谁、到期」只在 `未结待办.md`，交接不抄；(b) 每步「去哪、做什么、算对」写在第③节，每步 ≤ 5 行；(c) 超过 5 行的做法写进方案 / 手册 / 工作记录里的具体文件，第③节指「文件 + 第几节」。
> **只许指四类**：账上编号、正式文件（方案 / 手册 / 契约 / `pipeline/停了怎么办.md`）、工作记录里的具体文件、决策台账 D 号。**不准指**旧交接、记忆、「上一份」。
> **不进交接**：通用规矩（进 `CLAUDE.md` 或 `停了怎么办.md`）、决定（进决策台账，写 D 号）、进展日志（进 `项目状态.md`）。
